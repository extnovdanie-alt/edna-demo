# E.D.N.A. — Demonstração

Emitente de Declarações e Normas de Acordo.

Demonstração estática de gestão de equipamentos, empréstimos, termos e devoluções, com 28 equipamentos fictícios em sete categorias.

## Como testar

Abra o site e escolha **Sou da TI** ou **Sou colaborador**. A senha de teste é `demonstracao`.

- TI: `ti.demo`
- Colaborador: `colaborador.demo`

Os registros ficam somente no navegador de cada visitante. O login, o envio de e-mails e os aceites são simulados; os PDFs são identificados como demonstração. Não há conexão com LDAP, Arturito, n8n ou outros sistemas corporativos.

Esta publicação não contém a planilha de inventário, banco de dados, credenciais ou registros reais. A imagem da mascote e a identidade visual foram fornecidas ou solicitadas para esta apresentação; não indicam um produto oficial.

O arquivo index.html inclui os recursos necessários para funcionar no GitHub Pages, sem instalação de dependências.
